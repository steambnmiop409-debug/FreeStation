## 1. DPO 유도 [유도 + K]
RLHF 목적(KL 정규화된 보상 최대화):
```
max_π  E_{x, y~π}[ r(x,y) ] − β · KL( π(·|x) ‖ π_ref(·|x) )
```
이 문제의 최적해는 닫힌 형태를 가진다:
```
π*(y|x) = (1/Z(x)) · π_ref(y|x) · exp( r(x,y) / β )
```
이를 r에 대해 뒤집으면
```
r(x,y) = β · log( π*(y|x) / π_ref(y|x) ) + β · log Z(x)
```
선호 모델을 Bradley–Terry로 두면 `P(y_w ≻ y_l | x) = σ( r(x,y_w) − r(x,y_l) )` 이고, 두 보상의 차에서 **분배함수 Z(x)가 상쇄**된다. 따라서 정책만으로 쓴 손실이 나온다:
```
L_DPO = − E[ log σ( β log π_θ(y_w|x)/π_ref(y_w|x) − β log π_θ(y_l|x)/π_ref(y_l|x) ) ]
```
- 논문의 요지와 일치한다: 보상 모델의 **재매개변수화**로 최적 정책을 닫힌 형태로 얻어 문제를 단순 분류 손실로 환원, 미세조정 중 LM 샘플링이 필요 없고 하이퍼파라미터 조정이 적으며, 기존 방법과 대등하거나 더 낫다 [A].

## 2. 변형들이 고친 것
| 방법 | 바꾼 점 | 근거 |
|---|---|---|
| **IPO** (ΨPO) | RLHF 관행의 두 가정(쌍별 선호를 점별 보상으로 취급 / 그렇게 맞춘 보상 모델이 정책이 샘플링하는 행동에도 일반화)을 문제 삼는 일반 목적 ΨPO. DPO는 두 번째 가정만 피한다. Ψ를 항등함수로 두면 효율적으로 최적화 가능한 특수형 | [A] |
| **KTO** | 쌍 선호 대신 ‘좋음/나쁨’ 이진 신호, 전망 이론 기반 손실 | [K] |
| **ORPO** | SFT 손실에 오즈비 항을 더해 기준 모델 없이 단일 단계 | [K] |
| **SimPO** | 보상을 길이 정규화 평균 로그우도로 정의 → **기준 모델 불필요**, 목표 마진 γ 추가. AlpacaEval 2 등에서 DPO를 최대 6.4점 앞선다(NeurIPS 2024) | [A] |
| **RLOO** | PPO의 복잡한 구성 없이 REINFORCE 계열이 더 단순하고 효과적일 수 있음(ACL 2024). 학습된 critic을 피한다 | [A] |
| **Self-Rewarding / SPIN** | 모델 자신이 보상(LLM-as-judge)을 만들거나 과거 모델 출력과 사람 데이터를 구분하도록 학습 | [K] |
| **Tülu 3** | 개방형 후처리 레시피·데이터·평가·코드를 모두 공개, 부정적 결과도 공개 | [A] |

SimPO의 보상은 `r(x,y) = (β/|y|) log π_θ(y|x)`, 손실에 마진 γ를 빼서 `−log σ( r(y_w) − r(y_l) − γ )` 로 기억한다 [K].

## 3. 한계와 과최적화
- **DPO의 암묵적 보상**은 과적합하거나 극단값으로 표류해, 선호된 응답의 확률마저 0에 가깝게 떨어뜨릴 수 있다는 후속 지적이 있다 [A, 2차 출처].
- **보상 과최적화(Gao 등)** [A]: 고정된 ‘골드’ 보상 모델이 사람 평가자를 대신하는 합성 설정에서 프록시 보상 모델에 대해 정책을 최적화(RL 또는 best-of-n)했을 때 골드 점수의 변화를 측정. 최적화 방식에 따라 함수 형태가 다르며, 계수는 보상 모델 파라미터 수에 따라 매끄럽게 변한다. 보상 모델 데이터 크기, 정책 크기, KL 계수도 변화시켰다.
- 이 분석을 **명시적 프록시 보상이 없는 직접 정렬 알고리즘(DAA)** 으로 확장한 연구가 있으며, GPT-4 승률을 골드 보상의 대용으로 쓴다 [A].
- 길이 편향: SimPO가 길이 정규화를 핵심 설계로 삼은 것 자체가 길이와 보상의 얽힘을 시사한다 [J].

## 4. 해석 [J]
- 선호 최적화의 발전은 대체로 **“RLHF의 불안정·비용 → 오프라인 단순 손실 → 그로 인한 새 편향(길이, 표류, 분포 이탈) → 정규화·마진·기준 제거”** 의 순환이다.
- 오프라인 DPO류는 데이터 분포 밖의 응답에서 신뢰가 낮고, 온라인 RL(RLOO, GRPO)은 비용이 크다. **검증 가능한 영역은 RLVR(06번), 주관적 영역은 선호 최적화**라는 분업이 정착하는 추세로 보인다(Tülu 3가 두 흐름을 한 레시피에 담는 사례 [A: 레시피 공개] / RLVR 포함 여부는 [K]).
- 선택 가이드(제 판단): 선호 데이터가 쌍으로 있고 비용이 중요하면 DPO/SimPO, 이진 피드백뿐이면 KTO, 온라인 샘플링이 가능하고 보상이 신뢰할 만하면 RLOO/GRPO.
