## 2. 모델별 위치
| 모델 | A | B | C | 확인된 내용 |
|---|---|---|---|---|
| **Chameleon** | 이산 토큰 | AR | 완전 공유 | 이미지를 이산 토큰으로 양자화해 **초기 융합(early-fusion) 토큰 기반 혼합 모달** 모델을 처음부터 학습. 임의 순서의 이미지·텍스트를 다룸. 34B가 캡션·VQA에서 Flamingo·IDEFICS를 능가하고 텍스트 전용 벤치마크는 경쟁력 유지, 장문 혼합 모달 생성에서 Gemini-Pro보다 60.4% 선호 [A]. (약 10T 토큰이라는 수치는 3차 요약에서 온 것이라 미확인) |
| **Emu3** | 이산 토큰(이미지·텍스트·비디오) | AR 단독 | 완전 공유 | 하나의 Transformer를 다음 토큰 예측만으로 학습, **확산이나 합성 구조 없이** SDXL·LLaVA-1.6을 능가한다고 보고. 다음 토큰 예측으로 비디오도 생성 [A]. 후속 Emu3.5는 10조 토큰 이상 [A, 검색 결과 기준] |
| **Show-o** | 이산 토큰 | AR + **이산 확산** | 완전 공유 | 하나의 Transformer에서 AR과 이산 확산을 결합, VQA·텍스트→이미지·인페인팅/외삽·혼합 모달 생성 지원(ICLR 2025) [A] |
| **Transfusion** | 연속 패치(+모달리티별 인코더/디코더 층) | **AR(텍스트) + 확산(이미지)** | 완전 공유(텍스트 인과, 이미지 양방향) | 최대 7B로 스케일링 법칙을 확립. 이미지를 이산 토큰으로 양자화해 언어모델을 학습하는 방식보다 **훨씬 잘 확장**. 7B·2T 멀티모달 토큰(텍스트 1T + 이미지 약 6.9억 장에 해당하는 또 다른 1T 패치)으로 같은 규모의 확산 모델·언어모델과 대등. 모달리티별 인코딩/디코딩 층이 도움이 되어 이미지를 **16개 패치**까지 압축 [A] |
| **Janus** | **이해용(SigLIP)·생성용(VQ) 분리** | AR | 공유 Transformer, 인코더 분리 | 하나의 시각 인코더가 이해와 생성의 정보 입자도 차이 때문에 최적이 아니라는 문제의식으로 두 경로를 분리. 기존 통합 모델을 능가하고 과제 특화 모델과 대등하거나 넘는다고 주장 [A]. 모델 규모는 후속 논문 설명에서 1B 또는 1.5B로 엇갈림 [A, 2차 출처] |
| **VAR** | 다중 해상도 토큰 맵 | **다음 스케일 예측** AR | – | 래스터 순서 대신 저해상도→고해상도 예측. ImageNet 256×256에서 FID/IS를 크게 개선, 추론 약 20배 빠름, 거듭제곱 스케일링 법칙(NeurIPS 2024 최우수 논문) [A] |
| **LLaDA-V** | 연속 시각 입력 | **마스크 확산**(언어) | 완전 공유 | LLaDA에 시각 지시 튜닝을 더한 순수 확산 기반 멀티모달 [A] |
| **Mixture-of-Transformers (MoT)** | 어느 구조에든 적용 | – | **모달리티별 분리**(FFN·어텐션 행렬·LayerNorm), 어텐션은 전역 | dense와 **동일한 연산 구조·FLOP**. Chameleon 7B 설정에서 텍스트·이미지 성능을 FLOP의 **55.8%** 로, 음성 추가 시 **37.2%** 로, Transfusion 설정에서 이미지 성능을 **1/3 FLOP** 로 맞춤(TMLR 2025) [A] |
| **MoMa** | 초기 융합 | AR | 모달리티 인식 전문가(MoE) | 복잡도 통제 실험에서 총 FLOP를 최대 3.7배 감소 [A, 검색 결과 기준]. Mixture-of-Mamba는 같은 아이디어를 SSM에 적용해 1.4B에서 Transfusion 설정의 이미지 손실을 학습 FLOP의 34.76%로 달성 [A, 2차 출처] |

## 3. 비교에서 읽히는 것 [J]
1. **이산 토큰 vs 연속 패치**: Transfusion은 이산 양자화가 확장성에서 불리하다고 주장하고 [A], Emu3·Chameleon은 이산 토큰만으로 경쟁력을 보였다 [A]. 둘 다 *자기 설정에서* 참이며, 같은 데이터·연산·평가에서 직접 비교한 증거는 이번에 확인하지 못했다.
2. **이해와 생성의 충돌**: Janus의 분리 인코더와 MoT의 모달리티별 파라미터는 모두 ‘한 가중치가 두 요구를 동시에 만족하기 어렵다’는 같은 진단에서 나왔다 [A: Janus 논지 / MoT 구조]. 즉 *완전 통합*보다 *부분 분리*로 수렴하는 경향이 보인다.
3. **연산 효율은 구조(C축)에서 얻는다**: MoT·MoMa는 모델 구조를 거의 바꾸지 않고 파라미터를 모달리티별로 나눠 FLOP를 크게 줄인다고 보고한다 [A]. 이는 주 구조 경쟁과 독립된 *곱셈적 이득*일 수 있다 [J].
4. **확산 언어모델과의 접점**: LLaDA-V, Show-o는 언어 쪽에도 확산을 쓰는 방향이다 → [심층 03](03-diffusion-language-models.md).
5. **월드 모델과의 접점**: Emu3.5를 ‘월드 학습자’로 보는 시도 등은 통합 멀티모달을 월드 모델로 확장하려는 흐름이다 → [심층 14](14-world-models-jepa-line.md).

## 4. 열린 질문
- 통합 모델이 이해·생성 각각의 *전용 모델*을 같은 연산에서 이기는가, 아니면 편의성의 이득인가?
- 모달리티별 분리가 규모가 커져도 유지되는 이득인가? (MoT는 7B 규모까지 보고)
- 평가: 이미지 생성(FID, 선호)과 이해(VQA 계열) 지표를 어떻게 한 척도로 합칠 것인가?
