## 1. 이론적 뼈대: LeCun의 제안 [A]
- 중심은 **구성 가능한 예측 월드 모델**로, 에이전트가 계획할 수 있게 한다. 행동과 학습은 미분 가능한 내재적 비용 함수들이 이끈다.
- 월드 모델은 새로운 종류의 에너지 기반 구조 **H-JEPA**(계층적 결합 임베딩 예측 구조)에 기반하며, 동시에 최대한 정보적이고 최대한 예측 가능한 계층적 추상 표현을 학습한다는 설명이다.
- 이는 arXiv 논문이 아니라 OpenReview 게재 입장 문서다 [A: 포럼 ID는 발표 소개 글들이 링크].

## 2. JEPA 계보
| 모델 | 핵심 | 근거 |
|---|---|---|
| **I-JEPA** | 비생성적 자기지도 학습. **한 문맥 블록에서 여러 대상 블록의 표현을 예측**, 손으로 만든 증강 불필요. 대상 블록이 충분히 크고 문맥 블록이 공간적으로 퍼져 있어야 함. ViT-Huge/14를 16개 A100으로 72시간 미만에 ImageNet 학습 | [A] |
| **V-JEPA** | 비디오에서 **특징 예측 목적만**으로 학습(사전학습 이미지 인코더·텍스트·음의 예시·재구성 없음). 200만 공개 비디오. ViT-H/16이 Kinetics-400 81.9%, SSv2 72.2%, ImageNet-1K 77.9% | [A] |
| **V-JEPA 2** | 100만 시간 이상의 영상·이미지로 행동 없는 JEPA를 사전학습한 뒤 소량의 로봇 상호작용 데이터로 예측·계획. SSv2 77.3%, Epic-Kitchens-100 행동 예측 recall@5 39.7. LLM과 정렬해 비디오 QA도 보고 | [A] |
| V-JEPA 2.1 / VL-JEPA / LLM-JEPA | 조밀한 특징, 비전-언어, 언어모델로의 확장 시도 | [A: 제목·간단한 설명만] |

**비판·한계** [A, 2차 출처]: JEPA를 대조 학습과 연결한 연구는 I-JEPA의 **붕괴(collapse) 방지**와 평균 패치 표현 측면의 한계를 지적한다.

| **DreamerV3** | 하나의 설정으로 150개 이상 과제에서 특화 방법을 능가. 정규화·균형·변환 기반 견고화로 안정 학습, 인간 데이터·커리큘럼 없이 마인크래프트 다이아몬드 최초 수집. 모델이 클수록 데이터 효율과 최종 성능이 오른다 | [A] |
| **Genie** | 라벨 없는 인터넷 영상으로 학습한 11B ‘파운데이션 월드 모델’. 시공간 비디오 토크나이저·자기회귀 동역학 모델·잠재 행동 모델. 행동 라벨 없이도 프레임 단위 조작이 가능한 세계 생성(ICML 2024). 한계: 비현실적 미래 환각, 16프레임 기억, 약 1FPS | [A] |
| **GAIA-1** | 영상·텍스트·행동을 입력으로 주행 장면을 생성하는 자율주행 월드 모델. 월드 모델링을 이산 토큰의 다음 토큰 예측으로 다루고 생성에 비디오 확산을 사용. 영국 도시 주행 데이터로 학습 | [A] |
| **Cosmos** | 물리 AI용 월드 파운데이션 모델 플랫폼(비디오 큐레이션, 확산·자기회귀 사전학습 모델, 후속 학습, 토크나이저)을 오픈 라이선스로 공개 | [A] |
| Emu3.5 | 멀티모달 모델을 ‘월드 학습자’로 보는 시도(10조 토큰 이상) | [A: 검색 결과 기준] |

## 4. 로보틱스와의 접점
- **VLA**: π0는 사전학습 VLM 위에 플로우 매칭 행동 전문가를 얹고, GR00T N1은 비전-언어 모듈과 확산 Transformer 행동 생성기를 결합한다. Gemini Robotics는 Gemini 2.0 기반 VLA와 공간·시간 추론 ER 모델을 제시 [A].
- V-JEPA 2의 ‘소량 로봇 데이터로 계획’ 주장과, 위 VLA들의 ‘대규모 로봇 데이터 + 사전학습 VLM’ 접근은 서로 다른 데이터 전략이다 [J].

## 5. 해석 [J]
1. **JEPA는 ‘무엇을 예측하지 않을 것인가’의 선택**이다. 픽셀 수준의 예측 불가능한 세부(잡음)를 피하는 대신 붕괴 방지라는 새 난점을 갖는다.
2. **생성형 월드 모델은 시각적 검증이 쉬운 대신 비용이 크고 환각 문제**가 있다(Genie의 한계 [A]).
3. 두 갈래의 우열을 가를 결정적 증거는 아직 없다. 판단 기준은 **계획 성능**(예측 모델로 실제 과제를 얼마나 잘 푸는가)이며, V-JEPA 2의 로봇 계획 결과 [A]가 그 방향의 증거지만 세부(과제 종류, 성공률)는 확인하지 못했다.
4. 언어모델 중심 노선(06, 07번)과의 관계: 월드 모델은 ‘텍스트 추론’과 보완적일 수도, 대안일 수도 있다. 이 갈림이 AGI 경로 가설의 핵심 쟁점이다(15번 문서).
