# 심층 15. AGI로 가는 길에 대한 다섯 가설 — 증거, 반증, 검증 가능한 예측

> **근거 표기** — **[A]** 이번 세션 검색으로 확인 / **[K]** 제 지식(원문 미대조) / **[J]** 제 해석·종합.
> **성격** — 이 문서는 개별 논문 요약이 아니라 **종합 분석**입니다. 가설 구분과 판정은 전부 [J]이며, 근거 열에 [A]/[K]가 붙은 것만 사실 주장입니다. 어느 논문도 AGI 도달 여부를 결정하지 못합니다.

## 0. 먼저: 이 질문을 어떻게 다룰 것인가
10번 심층 문서의 결론대로 AGI는 정의에 따라 판정이 달라진다. 여기서는 정의 논쟁을 피하기 위해 **“현재 시스템과 ‘범용 인간 수준 에이전트’ 사이의 격차를 무엇이 메우는가”** 라는 질문으로 바꿔, 서로 다른 다섯 가설을 비교한다. 가설들은 배타적이지 않다.

## 1. 다섯 가설 개요
| # | 가설 | 한 줄 주장 |
|---|---|---|
| H1 | **스케일 + RL + 추론 시 연산** | 지금의 LLM 노선을 사전학습·RL·추론 연산의 세 축으로 계속 키우면 충분하다 |
| H2 | **메모리·지속 학습 구조** | 핵심 결손은 ‘추론 중 학습하고 기억하는 능력’이며 구조 혁신이 필요하다 |
| H3 | **월드 모델·구현(embodiment)** | 텍스트 예측만으로는 한계가 있고 세계 동역학 모델과 행동 접지가 필요하다 |
| H4 | **개방형 진화·자기개선** | 사람이 설계한 학습 신호의 한계를 넘으려면 시스템이 스스로 과제와 자신을 개선해야 한다 |
| H5 | **프로그램 합성·신경-기호 결합** | 새 과제에 대한 샘플 효율적 일반화는 탐색/기호 구조를 결합해야 얻어진다 |

## 2. 가설별 증거와 반증
### H1. 스케일 + RL + 추론 시 연산
- **지지 증거**: 손실이 모델·데이터·연산에 거듭제곱 법칙 [A: Kaplan]. RLVR로 AIME 2024가 RL 중 15.6%→71.0% [A: R1]. 추론 연산을 난이도별로 배분하면 best-of-N 대비 4배 이상 효율 [A: Snell]. 1,000개 예시와 budget forcing만으로도 테스트 시점 스케일링 [A: s1]. 프런티어 모델이 문맥 내 음모를 포함한 다양한 에이전트 능력을 보임 [A: Apollo].
- **반증/제약**: 큰 k에서는 RL 모델의 pass@k가 기반 모델보다 낮다는 보고 [A: Yue 등], 단 ProRL은 반대 입장 [A]. 스케일링 법칙 계수의 불확실성 [A: 재현 시도]. 검증 가능한 영역에만 깨끗한 보상 [J].
- **검증 가능한 예측**: 같은 기반 모델에서 RL 연산을 10배 늘리면, 기반 모델이 풀지 못하는 과제의 큰 k pass@k가 올라가는가? (ProRL이 주장하는 방향 [A])

### H2. 메모리·지속 학습 구조
- **지지 증거**: TTT 층은 문맥이 길어질수록 퍼플렉시티가 계속 개선되고 Mamba는 16k 이후 개선 정체 [A]. Titans는 2M 토큰 이상 needle 과제 보고 [A]. 델타 규칙 계열이 선형 어텐션 대비 개선 [A: Gated DeltaNet]. 
- **반증/제약**: Titans 재구현은 항상 기준선을 이기지 못함 [A]. TTT-KV가 사실상 선형 어텐션이라는 재해석 [A: 제목]. 지속 학습의 고전적 난제(파국적 망각 — EWC가 대응 [A])는 시퀀스 내 적응과 다른 문제 [J].
- **검증 가능한 예측**: 같은 파라미터에서 하이브리드(어텐션+테스트 시점 메모리)가 긴 에이전트 궤적의 과제 성공률을 일관되게 높이는가?

### H3. 월드 모델·구현
- **지지 증거**: V-JEPA 2는 100만 시간 이상의 영상 사전학습 + 소량 로봇 데이터로 계획 [A]. DreamerV3는 단일 설정으로 150개 이상 과제, 인간 데이터 없이 마인크래프트 다이아몬드 [A]. Genie는 라벨 없는 영상에서 조작 가능한 세계 생성 [A]. 로봇 VLA(π0, GR00T N1, Gemini Robotics)의 교차 구현체 일반화 시도 [A].
- **반증/제약**: Genie의 환각·짧은 기억·약 1FPS [A]. I-JEPA 붕괴 방지의 한계 지적 [A]. LLM이 텍스트만으로도 광범위한 추론 능력을 보여왔다는 사실은 H3의 필요성 주장을 약화시킨다 [J].
- **검증 가능한 예측**: 월드 모델 기반 계획이 같은 데이터량의 모델 프리 방법보다 새로운 환경에서 샘플 효율이 높은가?

### H4. 개방형 진화·자기개선
- **지지 증거**: XLand에서 과제를 계속 바꾸는 개방형 학습이 모든 사람이 풀 수 있는 평가 레벨에서 보상을 얻는 에이전트를 낳았고, 고정 과제 분포의 RL은 실패 [A]. AdA는 10^40개 이상의 과제 공간에서 사람과 비슷한 시간 척도로 적응 [A]. DGM은 SWE-bench 20.0→50.0% [A]. AlphaEvolve는 4×4 복소 행렬 곱 48회 등의 발견과 자신의 기반 LLM 학습 가속 [A]. 입장 논문은 초인간 지능에 개방형이 필수라고 주장 [A].
- **반증/제약**: 성과는 평가기가 명확한 영역에 집중 [J]. 아이디어의 참신함은 실행 후 격차가 닫힘 [A: 43명 실행 연구]. 평가기 해킹 가능성 [K].
- **검증 가능한 예측**: 자기개선 곡선이 서로 다른 기반 모델과 새 벤치마크로 전이되는가? 개선이 다회 반복에서 포화되는가?

### H5. 프로그램 합성·신경-기호 결합
- **지지 증거**: ARC Prize 2024에서 최고 점수 33→55.5%를 만든 핵심 기법이 딥러닝 유도 프로그램 합성과 테스트 시점 학습 [A]. AlphaGeometry는 합성 증명 데이터로 학습한 언어모델 + 기호 연역 엔진으로 30문제 중 25문제 해결(이전 최고 10) [A]. FunSearch는 프로그램 탐색으로 cap set 신기록 [A]. 퓨샷 TTT 효과 [A: 제목].
- **반증/제약**: 소형 재귀 모델의 ARC 성과는 과제 특화 학습의 영향이 클 수 있고 자연 이미지 일반화에 실패 [A, J].
- **검증 가능한 예측**: 새로 공개되는 ARC 계열 과제(공개 분포 밖)에서 탐색 결합 시스템이 순수 End-to-End 모델보다 일관되게 우세한가?

## 3. 공통 병목 [J]
| 병목 | 관련 가설 | 현재 증거 |
|---|---|---|
| **검증기(평가기)의 품질** | H1, H4, H5 | RLVR은 검증 가능한 영역에서만 깨끗 [A]. 자기개선의 성과도 평가기가 명확한 영역에 집중 [A]. 프록시 최적화는 과최적화 [A] |
| **장기 과업 신뢰성** | 전체 | τ-bench에서 gpt-4o급도 50% 미만, pass^8 25% 미만(소매) [A]. RE-Bench: 8시간 예산에서 평균 전문가에 근접하나 최상위와 격차 [A]. MLE-bench: o1-preview+AIDE가 16.9%의 대회에서 최소 동메달 [A] |
| **샘플 효율** | H2, H3, H5 | ARC는 과제당 약 3개 예시에서 규칙 추론을 요구 [A, 2차]. 학습 효율을 지능의 중심에 둔 정의 [A: Chollet] |
| **감독·감시 가능성** | 전체 | CoT 모니터링의 유효성과 취약성 [A]. 잠재 추론은 감시를 어렵게 할 수 있음 [J] |
| **자기개선과 안전의 결합** | H4 | 문맥 내 음모 능력 보고 [A], 정렬 위장 [A] |

## 4. 서로 어떻게 맞물리는가 [J]
- H1의 RL은 **검증기**를 필요로 하고, H4의 자기개선과 H5의 탐색이 그 검증기(코드 실행, 증명 검사)를 공급한다. 즉 H1↔H4↔H5는 경쟁이 아니라 **같은 루프의 부품**일 가능성이 높다 (예: AZR은 코드 실행기를 검증기로 쓰는 자기 대국 [A]).
- H2와 H3는 **다른 종류의 결손**을 겨냥한다: 전자는 시간 축(기억·적응), 후자는 세계 접지(인과·물리).
- 현재 상용 추론 모델은 H1에 H5의 일부(코드 실행·도구)를 이미 섞고 있다 [J].

## 5. 지금 가장 정보 가치가 높은 실험 [J]
1. **통제된 RL 연산 스케일링**: 동일 기반 모델·레시피에서 RL 연산을 늘리며 큰 k pass@k와 OOD 과제 성능을 추적 (H1 판정).
2. **장기 에이전트 과제에서 구조 비교**: 동일 예산의 {Transformer, 하이브리드, 테스트 시점 메모리}를 RE-Bench류 8시간 과제에서 비교 (H2).
3. **계획 중심 월드 모델 평가**: 같은 로봇 데이터로 JEPA형·생성형·VLA의 새 환경 성공률 비교 (H3).
4. **자기개선 전이 시험**: DGM류 에이전트가 만든 개선이 다른 기반 모델·새 벤치마크로 이식되는지 (H4).
5. **ARC류 신규 분포**: 탐색 결합 vs End-to-End (H5).

## 6. 결론 [J]
- 지금의 증거는 **H1이 가장 강하게 검증되고 있지만 그 범위가 검증 가능한 영역에 한정됨**을 보여주며, H2~H5는 각각 특정 결손에 대한 유망한 증거를 갖되 *규모에서의 결정적 검증*이 부족하다.
- 따라서 가장 방어 가능한 진술은 “AGI로 가는 단일 경로는 아직 입증되지 않았고, 검증기·장기 신뢰성·샘플 효율·감독 가능성이 공통 병목”이라는 것이다.
- 안전 관점에서는 능력이 오르는 속도와 감시 수단(CoT 모니터링, 평가, 시스템 수준 통제)이 얼마나 함께 가는지가, 어떤 가설이 맞는지만큼 중요하다 [J].
