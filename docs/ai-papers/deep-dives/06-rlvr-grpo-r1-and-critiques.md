## 1. DeepSeek-R1의 구성 [A/K]
- **R1-Zero**: 지도 미세조정(SFT)을 첫 단계로 두지 않고 대규모 RL만으로 학습. 학습 중 추론 능력이 발달하지만 가독성이 낮고 언어가 섞이는 문제가 있었다 [A].
- **R1**: 이를 고치려 RL 이전에 콜드스타트 데이터와 다단계 학습을 추가. OpenAI-o1-1217과 대등한 추론 성능을 주장 [A].
- 기반은 DeepSeek-V3-Base이고 GRPO로 학습. 도입부 기준으로 AIME 2024 pass@1이 RL 중 15.6%에서 71.0%로 상승 [A].
- RL이 자기 성찰·검증 같은 행동을 낳는다고 보고하며, 큰 모델의 추론 패턴을 작은 모델로 증류할 수 있어 1.5B~70B의 Qwen·Llama 기반 6개 증류 모델을 공개 [A].
- 보상은 규칙 기반(정답 정확도 + 형식)이라고 알고 있고, 단계는 콜드스타트 SFT → 추론 RL → 기각 샘플링 SFT → 전 영역 RL로 기억한다 [K].

## 2. GRPO: 가치 모델을 없앤 PPO 변형
- 가치(critic) 모델 없이 **그룹 점수로 기준선(baseline)** 을 추정해 학습 자원을 크게 줄인다. PPO는 정책·참조 정책·가치 함수가 필요하지만 GRPO는 앞의 둘만 필요하다 [A].
- 한 질문 q에 대해 G개 응답을 뽑아 보상 r_i를 얻고 [K]:
```
A_i = ( r_i − mean(r) ) / std(r)
J(θ) = E[ 1/G Σ_i 1/|o_i| Σ_t min( ρ_{i,t} A_i , clip(ρ_{i,t}, 1−ε, 1+ε) A_i ) ] − β · KL( π_θ ‖ π_ref )
ρ_{i,t} = π_θ(o_{i,t} | q, o_{i,<t}) / π_old(o_{i,t} | q, o_{i,<t})
```
- 같은 질문에서 **상대적으로** 나은 응답에 양의 이득을 준다는 점이 핵심이다 [K].

## 3. 구현 세부가 결과를 바꾼다: Dr. GRPO와 DAPO
**Dr. GRPO** [A]
- R1-Zero식 학습을 기반 모델과 RL 두 측면에서 분석. DeepSeek-V3-Base가 이미 ‘아하 순간’ 행동을 보이고, Qwen2.5 기반 모델은 프롬프트 템플릿 없이도 잘 추론한다 → 사전학습 편향 가능성.
- GRPO에 **최적화 편향**이 있어 응답 길이를 부풀린다(특히 오답에서). 이를 바로잡는 Dr. GRPO를 제안, 최소 레시피로 AIME 2024 43.3%.
- 편향의 기전은 제 추론으로는 이렇다: 손실을 응답 길이 |o_i|로 나누면, 음의 이득을 받는 긴 응답은 토큰당 벌점이 작아진다 [J/K, 논문 설명 미확인].

**DAPO** [A]
- 네 가지 기법: **Clip-Higher**(상한 클리핑이 낮은 확률 토큰의 탐색을 막는다고 보고 상한을 키움, 예: ε_high=0.28), **Dynamic Sampling**(전부 정답이거나 전부 오답인 그룹을 걸러 유효 기울기 유지), **토큰 수준 정책 경사 손실**(시퀀스 평균 대신 배치 전체 토큰 평균 → 긴 시퀀스가 더 큰 비중), **Overlong Reward Shaping**(잘린 샘플에 길이 인지 벌점, 우선 잘린 샘플 손실 마스킹).
- Qwen2.5-32B 기반 AIME 2024 **50점**. 단순 GRPO는 30점이었고 원인은 엔트로피 붕괴, 보상 잡음, 학습 불안정으로 분석.
- 비판: 토큰 수준 손실은 손실 계산만 정규화할 뿐 이득이 시퀀스 내 모든 토큰에서 같아 세밀한 신용 할당 문제는 남는다는 후속 논문의 지적 [A, 2차 출처].

**Kimi k1.5** [A]: 강화학습 기반 멀티모달 LLM의 학습 레시피. short-CoT 설정에서 AIME 60.8, MATH500 94.6, LiveCodeBench 47.3.

## 4. 핵심 논쟁: RL은 새 능력을 만드는가?
| 입장 | 근거 | 출처 |
|---|---|---|
| **선택/정제** | RLVR 모델은 작은 k에서는 기반 모델을 앞서지만 **k가 크면 기반 모델의 pass@k가 더 높다**. 추론 능력은 기반 모델에서 비롯되고 그에 한정된다 | Yue 등 [A] |
| **선택/정제(보조)** | 기반 모델이 이미 ‘아하 순간’ 행동을 보임, 템플릿 없이 추론 | Dr. GRPO [A] |
| **확장 가능** | 회의적 결론은 방법론적 제약 때문일 수 있고, 충분히 오래 RL하면 기반 모델에 없던 풀이 경로를 발견 | ProRL [A] |
| **조건부** | 분포 내 과제에서는 pass@128 기준으로 기반 모델을 넘지 못하지만, 기반 모델 역량을 벗어난 더 어려운 과제에서는 일관되게 개선 | Interplay [A] |
| **정책 선택** | ‘새 능력 학습이 아니라 희소한 정책 선택’이라는 관점 | 2605.06241 [A: 제목만] |

- 관련: s1은 단 1,000개 예시의 SFT와 ‘Wait’ 삽입(budget forcing)만으로 테스트 시점 스케일링을 얻어 o1-preview를 최대 27% 앞섰다고 보고 [A] — 추론 행동이 소량 데이터로 **끌어내질** 수 있음을 시사.
- **데이터 없는 RL**: Absolute Zero는 하나의 모델이 과제를 제안하고 풀며, 코드 실행기가 검증 신호를 준다. 코딩·수학에서 ‘zero’ 모델들을 앞섰다고 보고 [A]. SPIRAL(제로섬 게임 자기 대국), TTRL(테스트 시점 RL)도 같은 방향 [A: 제목만].

## 5. 해석 [J]
1. **‘선택 vs 발견’은 pass@k의 k와 과제 난이도에 의존하는 질문**이다. k=1에서의 개선은 확률 질량의 재배분만으로도 설명되므로, 능력 확장 여부는 큰 k 또는 기반 모델이 풀지 못하는 과제에서 따져야 한다. 위 표의 서로 다른 결론은 상당 부분 이 설정 차이로 설명될 수 있다.
2. **RLVR의 적용 범위 = 검증기가 있는 영역.** 수학·코드처럼 규칙 검증이 가능한 곳에서만 보상이 깨끗하다. 개방형 과제로의 확장은 보상 모델이 필요하고, 그 순간 과최적화 문제(Gao 등 [A])가 되돌아온다.
3. **길이는 성능의 ‘대리 변수’가 되기 쉽다.** Dr. GRPO·DAPO 모두 길이 관련 편향·보상 설계를 다룬다. 긴 사고 사슬이 곧 좋은 추론이라는 가정은 위험하다.
4. 같은 기반 모델에서 학습 레시피(클리핑, 샘플링, 정규화)만 바꿔도 AIME가 30→50으로 달라진 사실 [A]은, 논문 간 비교가 **기반 모델·레시피를 통제하지 않으면** 의미가 약하다는 뜻이다.

## 6. 읽을 때 체크리스트

- 기반 모델이 동일한가? 사전학습 데이터에 평가 문제와 유사한 풀이가 포함됐을 가능성은?
- 보상이 정답 규칙 기반인가, 학습된 보상 모델인가? 형식 보상이 지표를 부풀리지 않는가?
- 응답 길이 변화가 보고되는가?
