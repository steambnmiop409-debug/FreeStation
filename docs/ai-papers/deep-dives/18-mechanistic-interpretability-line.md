## 1. 이론적 출발: 중첩(superposition)
- **Toy Models of Superposition** [A]: 한 뉴런이 서로 무관한 여러 개념을 담는 **다의성(polysemanticity)** 을 장난감 모델이 완전히 설명할 수 있다고 주장. 네트워크는 희소한 특징을 **중첩**해 저장한다. 연구는 **상변이(phase change)**, 균일 다면체의 기하와의 연결, 적대적 예제와의 연결 증거를 보고하고 기계적 해석가능성에 대한 함의를 논한다.
- 후속: 용량 관점에서 특징이 차지하는 용량이 1/2 근처에 ‘붙는’ 넓은 영역이 있다는 보고, 특이 학습 이론으로 상변이를 분석(2차원 은닉에서 정다각형이 임계점)한 연구, 최근에는 부분 표현에서 완전 표현으로의 전이가 연속적이라는 연구가 있다 [A, 검색 결과 기준].
- **의미 [J]**: 뉴런 하나하나를 해석하려는 시도가 구조적으로 막히는 이유를 제공하고, 뉴런이 아닌 *특징 방향*을 찾아야 한다는 동기를 만든다.

## 2. 회로와 학습 동역학
- **유도 헤드(Induction Heads)** [A]: 문맥 내 학습이 생기는 시점에 손실이 급격히 떨어지는 ‘상변이’가 일어나며, 이는 학습률·워밍업·가중치 감쇠 스케줄 변화와 맞물리지 않고 다른 데이터셋에서도 재현된다. 토큰 수준 분석에서 개선의 대부분은 반복된 시퀀스에서 나타났다.
- **쟁점** [A, 2차 출처]:
  - 활성화 클램핑으로 도약을 만드는 **세 하위 회로**를 식별한 연구.
  - 마르코프 연쇄의 문맥 내 학습에서 유니그램식 예측 단계를 거친 뒤 올바른 바이그램 해로 급전환하며, 단순한 유니그램 해가 바이그램 해를 지연시킬 수 있다는 연구.
  - 2025년 연구는 **유도 헤드의 도약이 답이 이미 문맥에 있을 때만 ICL을 설명**하며, 메타 학습 설정에서는 여러 단계에서 각기 다른 회로가 나타난다고 주장. 다중 헤드 모델에서는 회로가 급변해도 정확도 곡선이 매끄러워 보일 수 있다.
- **Grokking** (Nanda 등) [A]: 모듈러 덧셈을 학습한 소형 Transformer를 역공학해 **이산 푸리에 변환과 삼각함수 항등식으로 덧셈을 원 위의 회전으로 바꾸는 알고리즘**을 찾아냈다. 임베딩이 핵심 주파수의 sin/cos로 입력을 보내고 어텐션·MLP가 이를 결합한다. 이로부터 진행 척도를 정의해 학습을 **암기 → 회로 형성 → 정리(cleanup)** 의 세 연속 단계로 나누고, grokking이 갑작스런 전환이 아니라 구조화된 메커니즘의 점진적 증폭 후 암기 요소 제거라고 주장. 저자들 스스로 **단일 회로로 풀리는 단순 과제의 개념 증명이며 분석에 상당한 수작업**이 들었다고 한계를 밝힌다.
- **의미 [J]**: ‘회로를 찾는다’가 *가능은 하나 수작업 비용이 크다*는 현실 때문에, 자동화·규모화(SAE, 귀속 그래프)로 연구 방향이 이동했다.

## 3. 지식 편집
- **ROME** [A]: 사실 연관이 **국소화되어 직접 편집 가능한 계산**에 대응한다고 보고. 인과 개입으로 사실 예측을 결정하는 단계가 **중간 층 피드포워드 모듈**(주어 토큰 처리 시)에 있음을 찾고, 랭크-원 편집(ROME)으로 가중치를 바꿔 zsRE에서 성능을, 새 반사실 데이터셋에서 특이성과 일반화를 함께 유지한다고 주장(다른 방법은 하나를 희생). v1 제목은 ‘…Factual Knowledge…’였고 ‘아는 뉴런/말하는 뉴런’ 구분을 논했다.
- 이후 ‘관계 연상을 다시 보는’ 후속 제목들이 보인다 [A: 제목만]. 편집의 *일반화·부작용*은 별도 검증이 필요하다 [J].

## 4. 희소 오토인코더(SAE): 특징을 대량으로 뽑기
| 연구 | 확인된 내용 | 근거 |
|---|---|---|
| Cunningham 등 | SAE를 중첩에서 특징을 분리하는 **확장 가능한 비지도** 접근으로 제시. 자동 해석 기준으로 더 해석 가능하고 비교 방법보다 더 단의미적이며, 레이블 없는 활성화만 필요하고 원 모델 학습보다 훨씬 적은 연산. Pythia에서 ‘법원 사건’, ‘성(姓)’ 같은 특징. 회로 지도화·표적 모델 편집에 활용 가능성 | [A] |
| OpenAI의 스케일링 | k-희소 SAE로 희소성을 직접 제어해 재구성-희소성 절충을 개선, 큰 규모에서도 죽은 잠재 변수가 거의 없고, 크기·희소성에 대한 깔끔한 스케일링 법칙. 특징 품질 지표(가설 특징 복원, 활성화 패턴 설명 가능성, 하류 효과의 희소성). GPT-4 활성화에 **1,600만 잠재 변수** SAE를 **400억 토큰**으로 학습 | [A] |
| Gemma Scope | Gemma 2 2B·9B의 모든 층·하위층과 27B 일부 층, 그리고 9B 지시 튜닝 모델용 SAE 공개(JumpReLU). 학습 비용 때문에 산업 밖 연구가 제한되는 문제를 겨냥 | [A] |
| Anthropic 3부작 | *A Mathematical Framework for Transformer Circuits*(어텐션 전용 소형 모델 회로, 유도 헤드로 ICL 설명) → *Towards Monosemanticity*(1층 Transformer에 SAE를 적용해 뉴런보다 해석 가능한 특징을 얻음; 저자들은 희소 구조 접근과 표준 사전 학습이 각각 문제(후자는 과적합)를 보여 SAE 경로를 택했다고 설명) → *Scaling Monosemanticity*(Claude 3 Sonnet 중간 층; 유명 인물, 국가·도시, 코드 타입 시그니처 등 **추상적·다국어·멀티모달** 특징; 특징이 추상 행동에 **반응할 뿐 아니라 인과적으로 일으킨다**). 저자들은 ‘해석 가능한 특징이 존재함’의 증명이지 대부분이 해석 가능하다는 주장은 아니며, 아마 **전체 특징의 작은 일부만** 추출했을 것이라고 인정 | [A, transformer-circuits.pub 검색 결과] |
| 귀속 그래프 (Biology) | 특징(노드)과 그 사이 인과 연결(엣지)로 *프롬프트에서 응답까지의 중간 단계*를 부분적으로 추적. 가지치기와 ‘슈퍼노드’ 묶음, 이후 **교란 실험으로 가설 검증**. 다단계 추론, 계획, 환각 등을 다룸. 대상은 Claude 3.5 Haiku | [A] |
| 재현성 | **같은 데이터로 학습한 SAE도 서로 다른 특징을 학습**한다는 연구, 외부 데이터 의존성 없이 충실한 특징을 얻으려는 FaithfulSAE | [A: 제목] |

## 5. 안전 응용과 그 한계
- **탐침(probe)** 기반 탐지: Sleeper Agents에서 선형 탐침이 *인공* 백도어를 높은 정확도로 탐지한다는 후속이 있으나, 이것이 학습에서 자연 발생한 기만에 일반화되는지는 의문이라는 논의 [A, 2차 출처]. 정렬 위장 탐지 탐침이 언제 잡고 언제 못 잡는지 다룬 연구도 있다 [A: 제목만].
- **사고 사슬 감시와의 관계**: 모델이 CoT를 쓰지 않거나 잠재 추론을 하면 내부 표현 해석이 유일한 창일 수 있다 [J, 심층 07 참조].

## 6. 해석 [J]: 무엇이 됐고 무엇이 안 됐나
| 질문 | 현재 증거 |
|---|---|
| 작은 알고리즘 과제의 회로를 역공학할 수 있나? | **예**(grokking 푸리에 알고리즘) — 단 수작업 큼 |
| 대형 모델에서 사람이 이해할 만한 특징을 대량으로 뽑을 수 있나? | **예**(SAE 스케일링) — 단 전체의 작은 부분, SAE 간 불일치 |
| 그 특징이 모델 행동을 *인과적으로* 설명하나? | 일부 **예**(특징 조작이 행동을 일으킴, 귀속 그래프의 교란 검증) |
| 안전 판단(기만·오정렬 탐지)에 신뢰할 만하게 쓸 수 있나? | **아직 미검증** — 인공 백도어 탐지 이상의 근거는 부족 |
- *가장 큰 병목은 평가*다. “이 특징이 정말 이 모델의 계산 단위인가”와 “설명이 충실한가”를 재는 합의된 기준이 없다 [J].
- 정리: 해석가능성은 *가능성의 증명*에서 *도구의 신뢰성 평가* 단계로 넘어가는 중이다.
