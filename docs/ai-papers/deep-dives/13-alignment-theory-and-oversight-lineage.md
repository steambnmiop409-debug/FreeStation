## 2. 문제 설정의 이동 [J]
1. **명세(2016~2018)**: 보상을 어떻게 정확히 쓰고 해킹을 막을까. → 보상 모델링으로 이동.
2. **감독의 확장(2018~2023)**: 인간이 평가할 수 없는 과제를 어떻게 감독할까. → 토론, 약-강 일반화, 반복적 증폭.
3. **일반화·내부 목표(2022~)**: 학습 분포 밖에서도 의도한 목표를 유지하는가. → Ngo 등의 논증, 그리고 정렬 위장·창발적 오정렬 같은 실증(12번 문서).
4. **측정과 거버넌스(2023~)**: 위험 능력을 어떻게 재고, 배포 결정에 연결할까. → 위험 능력 평가, 규제 제안.
5. **시스템 수준 통제(2025~)**: 모델이 정렬되지 않았을 가능성을 **가정**하고도 피해를 제한하는 장치(모니터링, 접근 제어)를 겹쳐 쌓는다는 DeepMind의 관점 [A].

## 3. 반복 등장하는 긴장 [J]
- **감독자가 약할 때**: 약-강 일반화 실험은 ‘약한 감독으로 강한 모델을 어디까지 이끌 수 있는가’의 유비 실험이며, 현재 결과는 부분적 성공이다 [A]. 인간-초인간 관계로의 외삽은 미검증이다.
- **측정의 한계**: 위험 능력 평가가 ‘능력 없음’을 증명하는 것은 어렵다(음성 결과의 의미) — 평가가 능력을 충분히 끌어냈는지 불확실 [J; 평가 논문이 ‘강한 위험 능력 없음’을 보고하면서도 초기 경고 신호를 언급 [A]].
- **프록시 최적화**: 보상 모델링, 선호 최적화, RLVR 모두 프록시에 대한 최적화이고, 과최적화는 경험적으로 확인된 현상이다 [A].
