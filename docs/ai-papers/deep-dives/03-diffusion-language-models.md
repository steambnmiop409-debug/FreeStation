## 1. 정식화: 마스크 확산 [K]
- **순방향**: 시각 t∈(0,1]마다 각 토큰을 독립적으로 확률 t로 `[MASK]` 처리한다. t=1이면 전부 마스크.
- **역방향(모델)**: 마스크된 시퀀스를 입력으로 받아 가려진 위치의 원래 토큰을 예측하는 Transformer. 어텐션은 **양방향**(인과 마스크 없음).
- **손실**:
```
L(θ) = − E_{t, x0, xt} [ (1/t) Σ_i 1[x_t^i = M] · log p_θ( x0^i | x_t ) ]
```
이는 −log p_θ(x0)의 상한(변분 하한)이다 [K]. 1/t 가중치는 마스크 비율이 낮을수록(문맥이 많을수록) 큰 가중을 준다.
- **생성**: 전부 마스크된 길이 L의 시퀀스에서 시작해, 매 단계 모든 마스크 위치를 예측한 뒤 일부는 확정하고 나머지는 다시 마스크한다(신뢰도가 낮은 것을 다시 마스크하는 전략 등) [K].
- 자기회귀(AR)와의 관계: AR은 ‘항상 오른쪽 한 토큰을 가리는’ 특수한 순서이고, 마스크 확산은 가림 패턴이 무작위인 일반화로 볼 수 있다 [J].

## 3. 왜 관심을 받는가 / 약점은 무엇인가
**장점(주장되는 것)**
- 병렬 디코딩으로 지연을 줄일 가능성, 임의 위치 채움(infilling)·제어 용이 [A: Dream, Block Diffusion 초록].
- 양방향 문맥을 쓰므로 역전 질문에 강할 수 있음 [A: LLaDA 초록의 역전 시 완성 결과].

**약점(문서화된 것)**
- 우도 모델링이 AR에 뒤처지고 고정 길이 생성에 제한된다는 것이 Block Diffusion의 출발점이다 [A].
- 완전 양방향 모델은 AR의 KV 캐시를 그대로 쓸 수 없어 단계 수를 줄이지 않으면 오히려 느릴 수 있다 [K/J].

## 4. 해석 [J]
- **‘역전 저주 해결’은 조심해서 읽어야 한다.** LLaDA의 근거는 시 완성이라는 한정된 과제의 비교이며 [A], 일반적 추론 능력의 우위를 뜻하지 않는다. 가림 위치가 무작위라 양방향 연관이 학습된다는 설명은 그럴듯하지만, 인과 검증은 별도 실험이 필요하다.
- **AR 초기화/변환의 흐름**(Dream, LLaDA2.0)은 확산 LM이 아직 ‘처음부터 학습’만으로는 AR의 막대한 사전학습 투자를 따라잡기 어렵다는 신호로 읽힌다 [J].
- **Block Diffusion이 가장 현실적인 절충**으로 보인다: 블록 간은 AR(캐시 사용), 블록 안은 확산(병렬).
