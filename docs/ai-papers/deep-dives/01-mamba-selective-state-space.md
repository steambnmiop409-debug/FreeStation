# 심층 01. Mamba와 선택적 상태공간모델 — ‘선택’이 바꾼 것과 못 바꾼 것

> **근거 표기** — **[A]** 이번 세션에서 웹 검색으로 확인한 초록·본문 발췌 / **[K]** 제가 알고 있는 내용이나 이번에는 원문과 대조하지 못함 / **[J]** 제 해석·평가(사실 주장 아님).

## 1. 풀려는 문제
- Transformer의 어텐션은 길이 L에 대해 연산 O(L²), 추론 시 KV 캐시가 L에 비례해 커진다 [K].
- 선형 어텐션, 게이트 합성곱, 순환 모델, 이전 SSM(S4 계열)은 효율을 얻는 대신 언어 같은 정보 밀집 모달리티에서 성능이 떨어졌다. 논문은 그 원인을 ‘내용에 기반한 추론을 못 하는 것’으로 진단한다 [K].
- 따라서 문제는 “고정된 크기의 상태 안에, **무엇을 남기고 무엇을 버릴지**를 입력 내용에 따라 결정하게 할 수 있는가”이다 [J, 위 진단의 재서술].

## 2. 구조를 단계별로
### 2.1 SSM의 기본형 [K]
```
h'(t) = A h(t) + B x(t)      (연속시간 상태 갱신)
y(t)  = C h(t)               (읽기)
```
A는 N×N(실제로는 대각 구조), B·C는 상태와 입력·출력을 잇는 투영이다.

### 2.2 이산화 [K]
간격 Δ로 이산화(영차 유지, ZOH)하면
```
Ā = exp(ΔA)
B̄ = (ΔA)^-1 (exp(ΔA) − I) · ΔB
h_t = Ā h_{t-1} + B̄ x_t ,   y_t = C h_t
```
고전 SSM(S4)에서는 Δ, A, B, C가 시간에 따라 변하지 않는다(LTI). 그래서 전체를 하나의 긴 합성곱 커널로 바꿔 병렬 학습할 수 있었다 [K].

### 2.3 선택성: 파라미터를 입력의 함수로 [K]
Mamba는 B, C, Δ를 입력 x_t의 함수로 만든다.
```
B_t = Linear(x_t),  C_t = Linear(x_t),  Δ_t = softplus(param + Linear(x_t))
```
A는 입력에 의존하지 않고 Δ를 통해서만 간접적으로 영향을 받는다. Δ의 직관은 RNN의 게이트와 비슷하다. Δ가 크면 상태를 리셋하고 현재 입력에 집중하며, Δ가 작으면 현재 입력을 무시하고 상태를 유지한다 [K].
- 이로써 모델은 토큰마다 “이건 기억에 쓴다 / 이건 흘려보낸다”를 정할 수 있다. 초록도 이를 ‘현재 토큰에 따라 정보를 선택적으로 전파하거나 잊는다’고 요약한다 [A].

### 2.4 대가: 합성곱을 못 쓴다 [A/K]
파라미터가 시간에 따라 변하면(time-varying) 시스템이 LTI가 아니어서 고정 커널 합성곱으로 바꿀 수 없다 [A: 검색 결과가 ‘입력 의존 파라미터가 고정 합성곱을 배제하고 순환 모드의 스캔을 쓴다’고 설명]. 학습은 결합법칙을 이용한 **병렬 스캔(associative scan)** 으로 한다 [K].

### 2.5 하드웨어 인식 구현 [A/K]
- 확장된 상태(B·L·D·N 크기)를 느린 GPU 메모리(HBM)에 만들지 않고, 이산화와 순환을 **빠른 메모리(SRAM)** 안에서 처리한다 [A].
- 역전파에서는 중간 상태를 저장하지 않고 재계산한다 [K]. FlashAttention과 같은 IO 인식 사고방식이다 [K].

### 2.6 블록 구조 [K]
어텐션과 MLP 블록을 따로 두지 않고, 게이트된 MLP와 SSM을 합친 단일 Mamba 블록(입력 투영 → 짧은 합성곱 → SiLU → SSM, 게이트 가지와 곱 → 출력 투영)을 쌓는다.

## 3. 보고된 결과 [A]
- 추론 처리량 Transformer 대비 5배, 길이에 선형, 실제 데이터에서 100만 길이까지 성능 향상.
- 언어: Mamba-3B가 같은 크기 Transformer를 능가하고 2배 큰 Transformer에 필적(사전학습·하류 평가). 오디오·유전체에서도 최고 수준.
- **합성 과제로 선택성의 효과를 분리** [A, 본문 기반 2차 출처]: 선택적 복사(Selective Copying)와 유도 헤드(Induction Heads)가 선택 파라미터 도입의 동기였다. 선택적 복사는 기억할 토큰의 위치가 달라져 내용 인식 필터링이 필요하고(실험은 길이 4096, 어휘 16), 유도 헤드는 문맥 인식 검색이 필요한 연상 회상 과제다. Mamba는 이를 풀고 **100만 토큰을 넘는 길이까지 외삽**한다고 보고했다. Griffin 논문도 자신의 모델이 선택적 복사를 풀었으며 Transformer는 외삽하지 못했다고 보고한다.

## 4. Mamba-2와 구조적 이중성(SSD)
- SSM과 마스킹된 어텐션 사이의 구조적 이중성을 규명하고, 이를 이용한 Mamba-2 층을 제안 [A].
- 인용 논문에 따르면 Mamba-2 핵심 층은 Mamba의 선택적 SSM보다 2~8배 빠르면서 언어모델링에서 Transformer를 계속 능가한다 [A, 2차 출처].
- 이중성을 얻기 위해 A를 ‘스칼라×단위행렬’ 형태로 제한한 것으로 알고 있다. 이 제한 덕분에 행렬 곱 중심 알고리즘이 가능해 텐서 코어를 활용하고 더 큰 상태 차원을 쓸 수 있다 [K].

## 5. 한계와 후속 논쟁
1. **고정 크기 상태 = 회상의 한계.** 선형 어텐션류가 연상 회상(associative recall)에서 약하다는 점은 후속 연구에서 반복 지적된다. Based 논문은 ‘회상-처리량 절충’을 주제로 하며, 상태가 작을수록 효율은 좋아지나 정밀 검색이 손해라고 인용된다 [A, 2차 출처].
2. **하이브리드의 부상.** 이를 보완하려는 Jamba, Samba(Mamba+슬라이딩 윈도 어텐션+MLP), Hymba, Griffin 등이 나왔고, ‘하이브리드 구조의 체계적 분석’ 논문들도 등장했다 [A: 제목·구조 설명 / 세부 결론은 미검토].
   - **Jamba** [A]: Transformer 층과 Mamba 층을 교차 배치하고 일부 MLP를 MoE로 바꾼 구조. 총 52B·활성 12B 파라미터로 80GB GPU 한 장에 맞추도록 설계했고, **256K 컨텍스트**를 지원한다. 256K 컨텍스트의 KV 캐시가 Jamba 4GB, Mixtral 32GB로 보고되며, 저자들은 일반 Transformer 대비 약 8배 작은 KV 캐시를 목표로 한다. Mixtral-8x7B 및 Llama-2 70B와 대등한 성능을 주장한다. Jamba-1.5는 Mini(총 52B/활성 12B)와 Large(총 398B/활성 94B).
3. **입력 형태 확장의 성과 편차.** MambaByte는 바이트 수준 모델 중 효율적이며 서브워드 Transformer와 경쟁한다고 보고 [A]. Vision Mamba(Vim)는 1248×1248 해상도에서 DeiT보다 2.8배 빠르고 GPU 메모리를 86.8% 절약한다고 보고 [A]. VMamba는 4방향 2D 선택 스캔으로 이미지 구조를 다룬다 [A].
4. **선택 메커니즘 자체에 대한 비판.** 후속 연구는 Mamba의 선택이 회상 과제에서 **국소 패턴 지름길**을 만들 수 있으며 이는 제약된 Δ 파라미터와 관련된다고 지적한다 [A, 2차 출처: 2410.15678]. 다른 연구들은 Mamba가 비슷한 과제를 Transformer보다 학습하는 데 훨씬 느리고, 복사 변형에서 학습 길이에는 맞추지만 일반화에 실패한다고 보고한다 [A, 2차 출처]. 합성 과제에서의 ‘해결’은 학습 설정에 민감하다 [J].
5. **소규모 재검증.** 구조 비교는 규모·학습 설정에 민감하다. Infini-attention을 소규모 사전학습에서 재검증하니 더 약한 결과가 나왔다는 사례처럼 [A], Mamba 계열도 규모별 재현이 중요하다 [J].

## 6. 해석 [J]
- Mamba의 기여는 ‘순환 모델도 **쓰기 게이트**를 내용 의존적으로 만들면 언어에서 경쟁할 수 있다’는 것을 보인 점이다. 이후 흐름(델타 규칙, 02번 문서)은 ‘무엇을 **어떻게 쓰는가**’를 개선했다.
- 순수 SSM이 정확한 복사·검색에서 어텐션을 대체하지 못한다는 증거가 쌓이면서, 현실적 최전선은 ‘대부분은 순환/SSM, 일부 층은 어텐션’인 하이브리드로 이동했다.
- 선택성이 만든 ‘병렬 학습의 어려움 → 커널 엔지니어링’ 이야기는, 아키텍처 연구가 하드웨어 구현 가능성과 분리될 수 없음을 보여준다.
