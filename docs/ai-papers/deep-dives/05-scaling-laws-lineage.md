# 심층 05. 스케일링 법칙의 계보 — Kaplan → Chinchilla → 데이터 한계 → 추론 시 연산

> **근거 표기** — **[A]** 이번 세션 검색으로 확인 / **[K]** 제 지식(원문 미대조) / **[J]** 제 해석 / **[계산]** 제가 제시된 수치로 직접 계산한 값.
> **한계** — 본문 열람 불가.

## 1. 1단계 — Kaplan (2020)
- 교차 엔트로피 손실이 파라미터 수, 데이터 크기, 학습 연산에 대해 **거듭제곱 법칙**을 따르며, 추세가 7자릿수 이상에 걸쳐 관찰된다 [A].
- 너비·깊이 같은 구조 세부는 넓은 범위에서 영향이 작다 [A].
- 과적합과 학습 속도에 관한 간단한 식을 주고, 이로부터 고정 연산 예산의 **최적 배분**을 추정할 수 있다고 한다 [A].
- 결과적으로 당시 업계는 ‘모델을 키우는 쪽’으로 기울었다 [K/J].

## 2. 2단계 — Chinchilla (2022)
- 70M~16B+ 파라미터, 5~500B 토큰 범위의 **400개 이상 모델**을 학습해, 연산 최적 학습에서는 **모델 크기와 토큰 수를 같은 비율로** 늘려야 한다고 결론 [A].
- Chinchilla는 70B 모델을 1.4T 토큰으로 학습해, 같은 연산의 Gopher(280B)보다 약 4배 많은 데이터를 썼고 Gopher·GPT-3·Jurassic-1·Megatron-Turing NLG를 폭넓은 하류 과제에서 능가. MMLU 평균 67.5%로 Gopher보다 7점 이상 높았다 [A].
- 널리 퍼진 휴리스틱은 ‘파라미터당 약 20 토큰’이다 [A, 후속 논문의 요약].
- 파라메트릭 형태 `L(N, D) = E + A/N^α + B/D^β` 와 이를 적합한 세 가지 접근(‘Approach 1~3’)이 쓰였다 [K; 재현 논문이 ‘3번째 접근=파라메트릭 적합’을 언급 [A]].

## 3. 신뢰도 검증 — 재현과 재검증
- **Epoch AI의 재현 시도**(Besiroglu, Erdil, Barnett, You) [A]:
  - 3번째 접근을 논문 그림에서 복원한 데이터로 재현했을 때, 보고된 추정치는 앞의 두 접근과 **불일치**하고 복원 데이터에도 잘 맞지 않았다.
  - 보고된 신뢰구간이 너무 좁아 **60만 회 이상의 실험**이 필요한 수준인데, 원 연구는 500회 미만으로 추정된다.
  - 원인으로 손실 스케일 선택 때문에 옵티마이저가 수렴 전에 멈춘 점과 본문 수치의 반올림이 지목됐고, 재유도한 3번째 접근은 앞의 두 접근과 부합한다.
  - 80% 구간이 원 보고보다 약 50배 넓다고 보고.
- 이후 ‘Kaplan과 Chinchilla의 조화’, ‘Chinchilla 스케일링의 견고성 평가’ 논문이 나왔다 [A: 제목 기준, 결론 미검토].
- **해석 [J]**: “20 토큰/파라미터”는 단일 상수가 아니라 **적합 절차와 데이터 범위에 의존하는 경험적 요약**으로 다루는 것이 안전하다. 그러나 ‘모델과 데이터를 함께 키운다’는 큰 방향은 재현에서도 유지된다(재현의 3번째 접근이 앞의 두 접근과 일치 [A]).

## 4. 3단계 — 추론 비용을 넣으면 최적점이 바뀐다
- 연산 최적(학습 비용만 최소화)과 **배포 최적**(추론 비용 포함)은 다르다. LLaMA는 추론 비용을 고려해 더 작은 모델을 더 오래 학습하는 방향을 택했다 [K].
- 보고된 수치로 계산해 보면 [계산]: Llama 3 최대 모델은 405B 파라미터에 약 15.6T 토큰 [A] → 약 38.5 토큰/파라미터로 ‘20’보다 훨씬 높다. Qwen2.5는 18T 토큰으로 사전학습 [A]. 파라미터별 비율은 모델 크기에 따라 다르다.
- **해석 [J]**: 최근 대형 공개 모델의 토큰/파라미터가 Chinchilla 값을 크게 넘는다는 것은, 업계가 ‘학습 연산 최적’이 아니라 ‘수명 주기 비용 최적’을 따른다는 정황이다.

## 5. 4단계 — 데이터가 부족해질 때
- 고유 데이터가 한정될 때, 같은 연산 예산에서 **최대 4 epoch** 반복은 고유 데이터 대비 손실 변화가 무시할 만하고, 하류 성능 차이는 약 4 epoch까지 미미하며, 의미 있는 이득은 약 16 epoch까지 가능하나 이후 수익이 급격히 줄어든다 [A]. 실험 범위는 최대 9B 파라미터, 9천억 토큰 [A].
- 다른 우회로: 데이터 선별(데이터 가지치기로 거듭제곱 법칙보다 빠른 감소 가능성 — 이론·실험 [K]), 합성 데이터와 그 위험(재귀 학습 시 모델 붕괴 [K]).

## 6. 5단계 — 학습 이후의 스케일링
- **추론 시 연산**: 문제 난이도에 따라 추론 연산을 배분하는 ‘연산 최적’ 전략이 best-of-N 대비 4배 이상 효율적이라고 보고 [A].
- **RL 연산**: LLM 강화학습에서 연산 규모에 따른 성능 변화를 다룬 연구가 등장 [A: 제목만].
- **해석 [J]**: 스케일링 축이 {모델, 데이터} 두 개에서 {사전학습 연산, RL 연산, 추론 연산} 셋 이상으로 늘었다. 이 축들 사이의 교환율은 아직 Chinchilla 같은 합의된 표가 없다.

## 6.5. 합성 데이터와 ‘모델 붕괴’ 논쟁
- **원 주장** (Shumailov 등) [A]: 모델 생성 콘텐츠로 학습하면 되돌릴 수 없는 결함이 생기고 **원래 콘텐츠 분포의 꼬리가 사라진다**. 이를 ‘모델 붕괴’라 부르며 VAE, 가우시안 혼합 모델, LLM에서 나타난다고 한다. 세대를 거치며 학습된 행동이 분산이 매우 작은 점 추정치로 수렴하고, 함수 추정 오차가 없는 거의 이상적인 조건에서도 불가피하다고 논증한다.
- **반론** [A: 제목·핵심 주장]: 합성 데이터가 실제 데이터를 **대체**하지 않고 실제 데이터와 **누적**되면 붕괴를 피할 수 있다는 연구(Gerstgrasser 등), 그리고 ‘모델 붕괴’라는 용어가 흔히 오해된다는 입장 논문이 있다 [A: 제목만].
- **해석 [J]**: 쟁점은 ‘합성 데이터가 나쁜가’가 아니라 *재귀 학습의 조건*(대체 vs 누적, 필터링 여부)이다. 실무적으로는 실제 데이터 비중 유지와 선별이 핵심이며, 합성 데이터 기반 레시피(교과서 품질 데이터 등)가 성공하는 이유도 이 조건에서 설명된다.

## 7. ‘창발’과 평가 지표
- 규모에서 갑자기 나타나는 능력(창발)을 정리한 논문과, 이것이 불연속·비선형 지표 선택의 산물일 수 있다는 반론이 공존한다 [K]. 스케일링 법칙을 능력 예측에 쓸 때는 지표가 연속적인지 먼저 확인해야 한다 [J].

## 8. 실무 요약 [J]
1. 학습 비용만 보면 모델·데이터를 함께 키우되, 계수를 맹신하지 말 것(재현 결과).
2. 배포가 길면 더 작은 모델을 더 오래 학습하는 편이 이득일 가능성이 높다(최근 공개 모델의 비율이 이를 시사).
3. 고유 데이터가 모자라면 반복은 약 4 epoch까지 비용이 거의 없다.
4. 추론 시 연산은 난이도별로 배분하는 것이 효율적이다.
