## 1. 통일된 관점: 연상 메모리 S에 (키 k, 값 v)를 쓰고 읽는다
선형 어텐션 계열의 상태는 행렬 S로, 읽기는 `o_t = S_t q_t`이다 [K]. 계열별 차이는 **쓰기 규칙**이다.

| 모델 | 쓰기 규칙 | 근거 |
|---|---|---|
| 선형 어텐션(헵 규칙) | `S_t = S_{t-1} + v_t k_tᵀ` | [K] |
| 게이트 선형 어텐션(GLA) | `S_t = G_t ⊙ S_{t-1} + v_t k_tᵀ` | [K] |
| DeltaNet | `S_t = S_{t-1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ` | [K] |
| Gated DeltaNet | `S_t = α_t S_{t-1}(I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ` | [K]; 게이팅=빠른 망각, 델타 규칙=정밀한 갱신이라는 상보성 [A] |
| TTT | `W_t = W_{t-1} − η ∇ℓ(W_{t-1}; x_t)` (상태 W는 모델 f의 가중치) | [A] |
| Titans | 깊은 메모리 M을 ‘놀라움(기울기)+모멘텀+망각’으로 갱신 | 개념 [A], 식은 아래 [K] |

### 1.1 델타 규칙은 한 스텝 경사하강이다 [유도]
손실 `ℓ(S) = ½‖S k − v‖²` 의 기울기는 `(S k − v) kᵀ` 이므로, 학습률 β의 한 스텝은
```
S' = S − β (S k − v) kᵀ = S (I − β k kᵀ) + β v kᵀ
```
이는 DeltaNet 식과 같다. 또 ‖k‖=1, β=1이면 `S' k = v` — 같은 키에 대한 이전 연상을 **덮어쓰고** 새 값을 정확히 저장한다.
- 헵 규칙은 이전 값을 지우지 않고 더하기만 하므로, 키들이 직교하지 않으면 **간섭**이 누적된다 [J, 위 유도에서 따라 나오는 해석].
- 행렬 상태(d_k×d_v)는 서로 직교하는 키를 최대 d_k개까지만 간섭 없이 담을 수 있다 [K].

## 2. 각 연구가 한 일
### DeltaNet / Gated DeltaNet
- DeltaNet을 **시퀀스 길이 방향으로 병렬 학습**하는 알고리즘을 제시해 중간 규모 언어모델링에서 실용화(NeurIPS 2024) [A]. 청크 단위 병렬화는 하우스홀더 곱의 WY 표현을 쓰는 것으로 알고 있다 [K].
- Gated DeltaNet은 게이팅과 델타 규칙을 결합하고 병렬 학습 알고리즘을 제시. 언어모델링·상식추론·문맥 내 검색·길이 외삽·장문 과제에서 Mamba2와 DeltaNet을 앞선다고 보고, 슬라이딩 윈도 어텐션 또는 Mamba2와의 하이브리드도 제안(ICLR 2025) [A].
- DeltaProduct(2502.10297)는 표현력을 하우스홀더 행렬의 곱으로 확장한다 [A: 제목만].

### TTT 층 (Sun et al.)
- 은닉 상태를 모델 f(가중치 W)로 보고 자기지도 손실에 대한 경사 한 스텝으로 갱신. 시퀀스를 처리하는 것이 곧 테스트 시점에 f를 학습하는 것이다 [A].
- 두 변형: 상태가 선형 모델(TTT-Linear), 2층 MLP(TTT-MLP) [A].
- 125M~1.3B에서 Transformer·Mamba와 비교해 대등하거나 우수. Mamba는 16k 문맥 이후 퍼플렉시티를 더 줄이지 못하지만 TTT는 문맥이 길어질수록 계속 개선. TTT-Linear는 8k에서 Transformer보다 빠르고 Mamba와 벽시계 시간이 비슷, TTT-MLP는 메모리 I/O 과제가 남음 [A].

### Titans
- 세 구성요소: 제한 윈도 어텐션(단기 기억), 신경 장기 기억(테스트 시점에 갱신), 학습 가능한 영속(persistent) 메모리 [A].
- 기대를 위반하는 사건을 더 강하게 저장한다는 ‘놀라움’ 개념에 기반 [A]. 식으로는 `S_t = η_t S_{t-1} − θ_t ∇ℓ(M_{t-1}; x_t)`(놀라움+모멘텀), `M_t = (1−α_t) M_{t-1} + S_t`(망각)로 알고 있다 [K].
- 메모리를 문맥으로 쓰는 MAC, 게이트로 쓰는 MAG, 층으로 쓰는 MAL 세 변형 [A]. 2M 토큰 이상의 needle 과제에서 확장된다고 보고 [A].

## 3. 비판과 재검증
1. **재현 가능성.** Titans를 가볍게 재구현한 연구는 청킹 때문에 항상 기존 기준선보다 낫지는 않다고 보고하며, 공개 코드 부재와 설명의 모호함이 재현을 어렵게 한다고 지적한다 [A]. 한 재구현 연구는 공개 코드가 MAL·MAG만 지원하고 MAC는 지원하지 않았다고 언급한다 [A, 2차 출처].
2. **대수적 동치 의심.** KV 결합 방식의 TTT가 사실상 선형 어텐션이라는 후속 연구가 있다 [A: 제목 기준, 본문 미검토].
3. **구현의 실용성.** ‘TTT Done Right’(대청크), 종단간 TTT 장문 연구, Atlas는 TTT 계열의 청크·최적화 설계를 다룬다 [A: 제목만].

## 4. 해석 [J]
- 이 계보의 가장 정직한 질문은 “학습 규칙이 **비선형·다단계**일 때 실제 이득이 있는가”이다. 선형 모델 + 한 스텝 업데이트는 델타 규칙/선형 어텐션과 수식상 같아지므로(위 1.1과 TTT-KV 동치 논의), TTT·Titans의 새로움은 (a) 비선형 메모리(MLP), (b) 모멘텀·망각 같은 옵티마이저 구조, (c) 미니배치 병렬화에서 나와야 한다.
- 실용적 승부처는 이론이 아니라 **청크 병렬화와 커널 구현**이다. TTT-MLP가 I/O에서 막힌다는 보고가 이를 보여준다 [A].
- ‘추론 중에 학습한다’는 관점은 지속 학습/AGI 논의와 닿아 있다. 다만 여기서의 ‘학습’은 한 시퀀스 안의 단기 적응이며, 파국적 망각을 줄이려는 EWC류(중요한 가중치의 학습을 늦춤 [A]) 지속 학습과는 문제 설정이 다르다.
